---
name: TikTok format
description: Vertical 9:16 1080×1920 formatting with captions and limited hashtags.
---

When editing or exporting for TikTok:

- Use a 9:16 aspect ratio at 1080×1920.
- Include captions on screen so the video works without sound.
- Use at most 5 hashtags.

Apply this only when the user is targeting TikTok. Otherwise ignore it.
