# Vex Desktop Video Editor

A beautiful Flet-based macOS desktop app wrapping the powerful Vex AI video editing agent.

## Features
- Natural language video editing via AI chat
- Real-time video preview with flet-video
- Visual timeline with thumbnails
- Project management
- Undo/Redo visual history stack
- Workflow wizards
- YouTube import
- Advanced export

## Quick Start
```bash
git clone https://github.com/andrewmp1/Vex-Desktop-Video-Editor.git
cd Vex-Desktop-Video-Editor
pip install -r requirements.txt
flet run main.py
```
