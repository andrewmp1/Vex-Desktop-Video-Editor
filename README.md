# Vex Desktop Video Editor

A beautiful desktop video editor powered by **natural language** and the [Vex](https://github.com/AKMessi/vex) AI agent.

Describe what you want done to your video in plain English — the AI handles the rest.

## Features (Planned)
- Natural language video editing
- Real-time video preview
- Timeline and undo/redo
- Powered by FFmpeg + LLMs
- Built with Flet for a native desktop experience

## Quick Start
1. Clone the repo
2. `pip install -r requirements.txt`
3. `flet run main.py`
